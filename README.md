# 公務人員行政中立線上實務測驗（10題單選）

> 依據 **基隆市政府人事處「公務人員行政中立宣導資料（107年8月編印）」** 製作之線上 10 題實務測驗系統。

🌐 **線上測驗網址（GitHub Pages）**：  
https://mulufang-sys.github.io/administrative-neutrality/

---

## 📝 測驗系統功能特色

1. **姓名輸入驗證**：進入測驗前需先輸入受測者姓名，方可開始作答。
2. **純題庫設計**：全卷僅呈現 10 題實務單選題與選項，去除冗長背景解說，聚焦實測。
3. **即時作答狀態**：顯示受測者姓名與即時作答題數統計（例如：已作答 5 / 10 題）。
4. **即時計分與結果核對**：
   - 送出答案後立即計算總分（滿分 100 分）及答對/答錯題數。
   - 每題清楚標示「答對」或「答錯」（提供正確選項核對，不附帶長篇解說）。
5. **支援重新測驗**：提供重測功能，可清空答案或更換姓名再次評量。
