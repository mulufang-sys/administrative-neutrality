# 公務人員行政中立線上實務測驗與成績管理報表系統

> 依據 **基隆市政府人事處「公務人員行政中立宣導資料（107年8月編印）」** 製作之線上 10 題實務測驗與成績管理後台系統。

## 🚀 系統功能架構

### 一、學員測驗前台 (`index.html`)
1. **姓名輸入驗證**：進入測驗前必須先輸入受測者姓名，方可開始答題。
2. **純 10 題實務測驗**：專注呈現 10 題單選題與選項，無多餘長篇解說。
3. **即時作答進度**：頂部即時顯示受測者姓名與作答進度（如：`已作答：5 / 10 題`）。
4. **自動結算與記錄**：繳卷後立即顯示總分與每題答對/答錯核對，同時**自動將該筆受測姓名、作答時間、各題答案與分數儲存至成績管理資料庫**。

---

### 二、成績管理後台與報表系統 (`admin.html`)
針對管理端需求，提供完整統計與報表輸出功能：

1. **管理員身分驗證**：具備密碼保護機制（預設密碼 `admin888`）。
2. **關鍵 KPI 數據看板**：
   - 累計受測總人數
   - 受測平均分數
   - 測驗及格率（≥60分及格人數與不及格人數）
   - 滿分人數（100分優秀人員）
3. **各題作答詳情追蹤**：
   - 資料表列出所有受測同仁名冊、繳卷時間、總分、是否及格。
   - 完整記錄每一位學員 **第 1 題至第 10 題分別選擇了哪一個選項、答案是對或錯**。
4. **各題答對率診斷分析**：
   - 自動統計 Q1 至 Q10 每題答對百分比，協助管理者診斷同仁最常混淆的法規盲點。
5. **多元成績報表輸出**：
   - 📥 **匯出 Excel (CSV) 報表**：自動附帶 UTF-8 BOM 編碼，使用 Microsoft Excel 開啟中文絕不亂碼。欄位包含序號、姓名、作答時間、總分、判定及 Q1~Q10 明細。
   - 🖨️ **一鍵列印成績報表 / 另存 PDF**：專屬公務報表排版，自動隱藏無關按鈕，呈現標準考核成績清冊。
   - 💾 **JSON 備份與匯入**：支援一鍵匯出完整數據 JSON 與匯入備份。
   - 🧪 **載入測試範例數據**：提供 5 筆預載範例資料，便於管理者在尚未有實際作答前預覽報表格式。
