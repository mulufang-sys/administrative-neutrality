# 公務人員行政中立宣導與線上互動測驗系統

> 依據 **基隆市政府人事處「公務人員行政中立宣導資料（107年8月編印）」** 數位化建置之現代化線上宣導與互動實務評量系統。

🌐 **線上展示網址（GitHub Pages）**：  
https://mulufang-sys.github.io/administrative-neutrality/

---

## 📖 系統特色與模組功能

本專案將公務人員行政中立法規、各類人員受規範情形、平時與選舉期間之行為態樣、實務案例及測驗題庫完整整合於單一輕量、免安裝、跨平台的網頁中：

1. **核心準則：行政中立「三不原則」**
   - 🕒 **不利用上班時間**：上班及勤務時間禁止從事政黨或政治活動。
   - 🏢 **不利用公家資源**：公物、公款、場所、房舍、人力、公務車等嚴格禁止動用於政治宣傳。
   - 🤝 **不利用職務關係**：嚴禁利用職權強求他人入黨、為候選人募款或干預他人投票權。

2. **規範對象分層解析**
   - **依法直接適用**：常任公務人員、機關首長、區長及依法任用之專任人員（含機要人員）。
   - **依法準用對象**：公立學校校長、兼任行政職教師、約聘僱人員、公營事業經營決策負責人（董事長/總經理/公股董監事）、行政法人專任人員。
   - **特別規範對象**：民選首長與政務人員（遵循《政務人員法草案》）、工友/技工/臨時人員（遵守《維持中立注意事項》）、駐衛警察（準用中立法）。

3. **行為態樣比較矩陣與紅線禁制**
   - 民選政務首長 vs 常任公務人員於「平日」與「選舉期間」之行為態樣（站台、助講、動用資源、出入拜票）對比。
   - 六大核心禁止事項清單。
   - 配偶及二親等以內血親、姻親參選之特別例外規定（得站台助講、大眾傳播媒體只具名不具銜）。

4. **實務爭議案例深入解析**
   - 案例一：常任文官請假參加「黨政文宣平台會議」的合法性與界線。
   - 案例二：公職候選人不請自來出席機關志工活動之處置與禁止差別待遇原則。
   - 案例三：警察局長請假為直轄市長「擬參選人」站台高喊凍蒜——為何技術未牴觸中立法仍受記申誡處分（官箴與社會觀感要求）。

5. **重要常見問與答（FAQ Accordion）**
   - 涵蓋政務官界線、連任參選人上台致詞、登記參選請假、政策研討會議出席等實務 Q&A。

6. **10 題線上即時評量測驗系統**
   - 即時進度追蹤、作答檢測。
   - 提交後即時計算總分（滿分 100 分）、依分數給予等級評語。
   - 每題均附帶詳盡法理依據、條文號次與案例延伸解析。
   - 提供「重新測驗」一鍵重置功能。

7. **JSON 原始結構化資料匯出**
   - 提供完整結構化 JSON 檔案（`1070828行政中立宣導資料.json`），支援一鍵複製與下載，方便串接各類題庫系統與數位學習平台。

## 📂 專案檔案結構

```text
├── index.html                   # 線上宣導與 10 題互動測驗單一整合應用程式 (HTML5 / CSS3 / Vanilla JS)
├── 1070828行政中立宣導資料.json   # 宣導手冊結構化摘要與 10 題選擇題庫完整 JSON 資料集
├── 1070828行政中立宣導資料.pdf    # 原始宣導資料 PDF (基隆市政府人事處編印)
└── README.md                    # 專案說明與法規導引文件
```

## 🚀 本地端運行

本專案無需任何建置工具（如 Node.js 或 Webpack），直接使用瀏覽器開啟 `index.html` 即可完整運行所有功能：

```bash
# 使用預設瀏覽器開啟
start index.html
```
